MCP integratsiya

OgAI MCP server manzili va serverning ishga tayyorlik holatini tekshiring.

Holat tekshirilmagan Server holatini tekshirish uchun tugmani bosing.
Bu manzilni ChatGPT yoki boshqa MCP mijozining Streamable HTTP sozlamalariga kiriting.

MCP mijoziga ulash

Transport: Streamable HTTP

Autentifikatsiya: Bearer token

Token sifatida Vercel Environment Variables ichidagi MCP_SHARED_SECRET qiymatidan foydalaning. Maxfiy token ushbu sahifada ko‘rsatilmaydi.

Holat indikatori MCP endpointi sozlanganini va server tekshiruviga javob berishini bildiradi. U ChatGPT yoki boshqa tashqi MCP mijozining ayni vaqtda faol ulangan sessiyasini aniqlamaydi.
